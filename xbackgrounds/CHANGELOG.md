# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-08-01

### Added

- `XParticles` — canvas particle background (home).
- `FlowFieldBg` — canvas flow-field particle background.
- `FloatingPaths` — animated SVG floating paths.
- `LightLines` — animated SVG light lines.
- `TerminalBgPaths` — animated layered bezier paths for terminal themes.
- `ColorRain` — canvas digital-rain background.
- npm package scaffolding (`dist` build, TS declarations, subpath exports).
